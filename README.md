# techishthoughts-org Homebrew tap

## gitshift

Switch Git, SSH, GPG and GitHub CLI identities between GitHub and GitLab accounts.

```bash
brew tap techishthoughts-org/tap
brew trust techishthoughts-org/tap
brew install --cask techishthoughts-org/tap/gitshift
```

Upgrade with `brew upgrade --cask gitshift`.

`Casks/gitshift.rb` is generated by GoReleaser from the
[gitshift release workflow](https://github.com/techishthoughts-org/gitshift/blob/main/docs/maintainers/releasing.md).
Do not edit it by hand; changes are overwritten on the next release.
